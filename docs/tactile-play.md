# Moremi tactile play update — 12 October 2026

The three adventures now follow Play → Make → Play rounds. Instruction worksheets are replaced by draggable objects, picture recipes, short goals, and generated clay sprites. Children can also select an object then tap its destination; native buttons support keyboard interaction.

- Blob: put snacks in a basket, set a price and multiplication tile, fill three orders, choose payments. Incorrect basket counts, incorrect totals, and broken app rules cannot award a star.
- Mushroom: move fruit to customers, connect sale/refill tiles, sell through an empty shelf and refill. Each intermediate event contributes to completion evidence.
- Sheep: dress the new cloud character, connect weather pictures to props, then use the resulting app for sunshine, rain and a changing-weather picnic.
- Saved creations reopen as the same interactive toys; existing drafts, awards and backups remain compatible.
- Scene clips autoplay muted and loop with no visible pause button. Visibility changes suspend/resume playback. Reduced-motion settings use posters and stop decorative motion.
- Generated assets use real alpha transparency and total approximately 208 KB as WebP. Sources and generation prompts are recorded separately.

Research direction: Sago Mini Fun Fair's movable props (https://sagomini.com/apps/fun-fair/) and Toca Boca World's open-ended role play (https://www.tocaboca.com/toca-boca-world). These informed direct manipulation and character situations, not copied artwork.

Verification: domain/evidence tests, complete rendered DOM journeys for all three games, wrong-answer rejection, storage failure/retry, actual pointer drag/cancel, onboarding/audio persistence, autoplay/reduced-motion. Browser visual verification unavailable in this environment; no claim of on-device layout inspection.
