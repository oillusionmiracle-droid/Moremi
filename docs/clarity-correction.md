# Moremi: build, run, understand

This correction responds to an overly detailed map and unclear app-building lessons.

- The world uses a quiet shape landscape and three separate, live landmarks. Decorative castles, flower beds and waterfalls no longer compete with the destinations.
- Mushroom introduces one piece at a time: stock display, starting value, Sell action, Refill action, then Run. The child presses the app's own button and sees its state and display change. The old arithmetic prediction screen is removed; its stored fields retain compatibility and record the observed runtime check.
- Sheep starts with a weather input, then introduces one IF/THEN connection at a time. Changing weather automatically updates PACK THIS. Tests run the child's actual rules; no manual dressing simulates automation. The saved app uses the same WeatherPad and interpreter.
- Existing makers, projects, paused drafts, evidence and reward records retain their current schema. No storage clearing or progress reset is introduced.
- Vercel now runs TypeScript, the production build and domain/DOM/offline tests before accepting a deployment. Local execution and browser/touch visual QA were unavailable for this correction.
